# A.N.T. interactive wireframe

เปิด `index.html` ด้วยเบราว์เซอร์ ใช้งานได้จากไฟล์โดยตรง ไม่ต้องติดตั้งแพ็กเกจหรือเชื่อมอินเทอร์เน็ต

- หน้าเริ่มต้น: กราฟเต็มจอ ไม่มีชื่อ node หรือแถบรายละเอียดถาวร
- Hover ขอบบน 24px: เมนูเลื่อนลง มีช่องค้นหาและตัวกรอง
- Hover node: แสดงชื่อ ประเภท และคำอธิบายสั้น ๆ
- คลิก node: เปิด side panel พร้อมข้อมูล ความสัมพันธ์ หลักฐาน และแหล่งที่มา
- คลิกความสัมพันธ์ใน panel: เปลี่ยนไปดูรายละเอียด node ที่เกี่ยวข้อง
- เมนูบุคคล / ผลงานวิชาการ / อาชีพ: เปิดหน้ารายการพร้อมช่องค้นหา ดูรายละเอียดหรือกลับไปแสดงในกราฟได้ (ผลงานวิชาการรวมสิ่งพิมพ์ โครงการ และรายวิชา)
- เลือก node: เน้นเส้นและ node ข้างเคียง พร้อมชื่อความสัมพันธ์บนเส้น
- คลิกพื้นที่ว่าง: ปิด side panel; การลากพื้นหลังยังเป็นการ pan และไม่ปิด panel
- ลาก node / ลากพื้นหลัง / เลื่อนล้อเมาส์: ย้าย node / pan / zoom
- Tab และ Enter ใช้เปิดข้อมูลได้; Escape ปิด panel หรือเมนู

ขอบเขต: wireframe ขาวดำ ใช้ข้อมูลสมมติทั้งหมด ไม่มี backend และไม่มีการประเมินระดับทักษะ ข้อมูลอ้างอิงเชิงโครงสร้างมาจากแนวคิด Academic Network & Talent Map ของโปรเจค A.N.T.

กราฟใช้ force simulation แบบง่ายใน JavaScript เพื่อทดลอง interaction โดยไม่ใช้ไลบรารีภายนอก

ไฟล์ `ANT-wireframe.html` เป็นเวอร์ชันรวม HTML/CSS/JavaScript ในไฟล์เดียวสำหรับเปิดใช้งานโดยตรง
