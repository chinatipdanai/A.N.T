Wireframe A.N.T.

ตัวอย่างโครงร่างขาวดำสำหรับทดลองการใช้งาน ไม่ใช่ข้อมูลจริง

  • วางเมาส์ขอบบนเพื่อเปิดเมนู
  • วางเมาส์บน node เพื่อดูข้อมูลสั้น ๆ
  • คลิก node เพื่อเปิดรายละเอียดด้านขวา
  • ลาก node เพื่อย้ายตำแหน่ง ลากพื้นหลังเพื่อเลื่อนกราฟ
  • เลื่อนล้อเมาส์เพื่อซูม
  • กด Tab เพื่อเลือก node และ Enter เพื่อเปิดรายละเอียด
  • กด Escape เพื่อปิดรายละเอียดหรือเมนู
