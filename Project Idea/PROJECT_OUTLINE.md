## 2. ที่มาและความสำคัญของโครงงาน

มหาวิทยาลัยและองค์กรมีข้อมูลเกี่ยวกับบุคลากรและกิจกรรมทางวิชาการหลายประเภท เช่น หลักสูตร รายวิชา โครงงาน งานวิจัย ผลงานตีพิมพ์ ใบรับรอง ทักษะ และประสบการณ์ฝึกงาน ข้อมูลเหล่านี้มักกระจายอยู่ในหลายฐานข้อมูลหรือหลายระบบ ทำให้การเข้าถึง การทำความเข้าใจ และการนำข้อมูลไปใช้ประกอบการตัดสินใจทำได้ยาก [1]

การที่ข้อมูลถูกจัดเก็บแยกส่วนยังทำให้มองเห็นความเชี่ยวชาญ ความสัมพันธ์ระหว่างบุคคล และโอกาสในการทำงานร่วมกันได้ไม่ชัดเจน โดยเฉพาะการค้นหานักวิจัยหรือผู้เชี่ยวชาญที่เหมาะสมสำหรับความร่วมมือระหว่างมหาวิทยาลัยกับภาคอุตสาหกรรม ซึ่งเป็นปัญหาที่มีการศึกษาไว้ก่อนแล้ว [2]

โครงงานนี้จึงเสนอแพลตฟอร์ม A.N.T. เพื่อรวบรวมและแสดงความสัมพันธ์ระหว่างบุคคล ทักษะ รายวิชา โครงงาน งานวิจัย ผลงานตีพิมพ์ ใบรับรอง และบทบาทงานในอุตสาหกรรม โดยใช้ Interactive Network Graph ร่วมกับ Force-Directed Layout เป็นการแสดงผลหลัก เพื่อช่วยให้ผู้ใช้สำรวจข้อมูลและเข้าใจความเชื่อมโยงขององค์ประกอบต่าง ๆ ได้ง่ายขึ้น [3]-[5]

ตัวอย่างเช่น ผู้ใช้สามารถค้นหาหัวข้อ Cybersecurity และดูบุคคลที่มีทักษะที่เกี่ยวข้อง พร้อมตรวจสอบหลักฐานสนับสนุนทักษะ เช่น รายวิชา โครงงาน งานวิจัย ใบรับรอง หรือประสบการณ์ที่เกี่ยวข้อง รวมถึงดูความเชื่อมโยงกับตำแหน่งงาน เช่น SOC Analyst ได้

KMUTT จะถูกใช้เป็นกรณีศึกษาในการพัฒนาและประเมินแพลตฟอร์ม โดยออกแบบโครงสร้างระบบให้สามารถปรับใช้กับมหาวิทยาลัยหรือองค์กรอื่นได้ในอนาคต

## 3. ปัญหาที่ต้องการแก้ไข

1. ข้อมูลบุคคล กิจกรรมทางวิชาการ ทักษะ และงานวิจัยถูกนำเสนอแยกจากกัน ทำให้เห็นความสัมพันธ์ระหว่างข้อมูลได้ยาก
2. ผู้บริหารมหาวิทยาลัยอาจไม่เห็นภาพรวมของความเชี่ยวชาญที่มีอยู่ภายในมหาวิทยาลัยอย่างชัดเจน
3. อุปสรรคด้านข้อมูลทำให้ค้นหาความร่วมมือทางวิชาการและงานวิจัยที่เหมาะสมได้ยาก
4. หน่วยงานภายนอกอาจค้นหาผู้เชี่ยวชาญสำหรับงานวิจัย การขอทุน หรือความร่วมมือได้ยาก
5. นักศึกษาอาจค้นหาข้อมูลเกี่ยวกับความร่วมมือของมหาวิทยาลัยและผู้ติดต่อทางวิชาการที่เกี่ยวข้องได้ไม่สะดวก

## 4. วัตถุประสงค์

1. พัฒนาวิธีแสดงศักยภาพและทักษะของบุคคลโดยอ้างอิงหลักฐาน เช่น รายวิชา โครงงาน งานวิจัย ผลงานตีพิมพ์ ใบรับรอง และประสบการณ์ทำงานหรือฝึกงาน
2. แสดงความสัมพันธ์ระหว่างบุคคล ทักษะ กิจกรรมทางวิชาการ งานวิจัย และบทบาทงานในอุตสาหกรรม
3. ช่วยให้ผู้ใช้ค้นหาบุคคลที่มีความเชี่ยวชาญใกล้เคียง และตรวจสอบข้อมูลที่สนับสนุนทักษะดังกล่าวได้
4. เปรียบเทียบทักษะที่มีอยู่กับทักษะที่จำเป็นสำหรับบทบาทงานที่กำหนด และระบุทักษะที่ควรพัฒนาเพิ่มเติม

## 5. กลุ่มผู้ใช้งานเป้าหมาย

> **ส่วนที่ควรยืนยันก่อนส่งอาจารย์:** ระบบจะรองรับผู้ใช้ทุกกลุ่มหรือเลือกเฉพาะบางกลุ่มในระยะแรก

- **ผู้บริหารมหาวิทยาลัย:** ดูภาพรวมความเชี่ยวชาญและศักยภาพภายในมหาวิทยาลัย
- **อาจารย์และนักวิจัย:** ค้นหาผู้ร่วมงานหรือผู้เชี่ยวชาญในหัวข้อที่สนใจ
- **นักศึกษา:** สำรวจทักษะ รายวิชา โครงงาน และเส้นทางที่เกี่ยวข้องกับอาชีพ
- **หน่วยงานหรือภาคอุตสาหกรรม:** ค้นหาผู้เชี่ยวชาญเพื่อความร่วมมือ งานวิจัย หรือการสนับสนุนโครงการ

## 6. ขอบเขตของโครงงาน

### 6.1 ขอบเขตด้านข้อมูล

- บุคคลหรือบุคลากรที่อยู่ในกรณีศึกษา
- ทักษะและหัวข้อความเชี่ยวชาญ
- รายวิชาและหลักสูตร
- โครงงาน
- งานวิจัยและผลงานตีพิมพ์
- ใบรับรองและประสบการณ์ฝึกงาน/ทำงาน
- บทบาทงานและทักษะที่ตำแหน่งงานต้องการ
- ความสัมพันธ์ระหว่างข้อมูลแต่ละประเภท

### 6.2 ขอบเขตด้านระบบ

- ฐานข้อมูลสำหรับจัดเก็บข้อมูลและความสัมพันธ์
- Backend API สำหรับจัดการและค้นคืนข้อมูล
- Frontend สำหรับแสดงผลข้อมูล
- การค้นหาและการกรองข้อมูลตามประเภทหรือหัวข้อ
- Interactive Network Graph ด้วย Force-Directed Layout
- หน้ารายละเอียดบุคคล ทักษะ หลักฐานสนับสนุน และบทบาทงาน
- ฟังก์ชันเปรียบเทียบทักษะกับความต้องการของบทบาทงาน
- การประเมินความเข้าใจและความสะดวกในการใช้งานของผู้ใช้

### 6.3 ขอบเขตที่ไม่รวมในระยะแรก

- ไม่รับประกันว่าข้อมูลจะแทนข้อมูลบุคลากรทั้งหมดของ KMUTT
- ไม่ใช้ระบบเพื่อการตัดสินใจรับเข้าทำงานหรือประเมินบุคคลโดยอัตโนมัติ
- ไม่เปิดเผยข้อมูลส่วนบุคคลหรือข้อมูลที่ไม่ได้รับอนุญาต
- การเชื่อมต่อกับระบบจริงของมหาวิทยาลัยจะทำเฉพาะเมื่อได้รับสิทธิ์และข้อมูลที่เหมาะสม

## 7. แนวทางการดำเนินงาน

1. ศึกษาปัญหา ความต้องการของผู้ใช้ และงานวิจัยที่เกี่ยวข้อง
2. วิเคราะห์แหล่งข้อมูลของ KMUTT และข้อมูลภายนอก รวมถึงสิทธิ์การเข้าถึง ความพร้อมใช้งาน และข้อจำกัด
3. ออกแบบโครงสร้างข้อมูลและแบบจำลองความสัมพันธ์ระหว่างโหนดและเส้นเชื่อม
4. ออกแบบสถาปัตยกรรมระบบ ฐานข้อมูล API และส่วนติดต่อผู้ใช้
5. พัฒนาโมดูลนำเข้าหรือจัดเตรียมข้อมูล การค้นหา การกรอง และการแสดงผลกราฟ
6. พัฒนาฟังก์ชันเปรียบเทียบทักษะกับบทบาทงาน
7. ทดสอบระบบด้วยข้อมูลตัวอย่างและตรวจสอบความถูกต้องของความสัมพันธ์
8. ประเมินการใช้งานกับกลุ่มผู้ใช้เป้าหมาย และสรุปข้อจำกัดของระบบ

## 9. ผลลัพธ์ที่คาดว่าจะได้รับ

1. แพลตฟอร์ม A.N.T. ที่สามารถแสดงความสัมพันธ์ระหว่างบุคคล ทักษะ รายวิชา โครงงาน งานวิจัย ผลงานตีพิมพ์ และบทบาทงานได้
2. Interactive Network Graph ที่ช่วยให้ผู้ใช้สำรวจบุคคล ทักษะ และหลักฐานสนับสนุนได้
3. ภาพรวมความเชี่ยวชาญและความสัมพันธ์ของทักษะภายในกรณีศึกษา KMUTT
4. ฟังก์ชันเชื่อมโยงหรือเปรียบเทียบความเชี่ยวชาญกับทักษะที่อุตสาหกรรมต้องการ
5. ผลการประเมินว่าผู้ใช้สามารถเข้าใจข้อมูลและความสัมพันธ์ที่ระบบนำเสนอได้หรือไม่
6. รายการข้อจำกัดของข้อมูลและระบบ เพื่อใช้ปรับปรุงหรือขยายผลไปยังองค์กรอื่น

## 10. แนวทางการประเมินผล

> **ส่วนสำคัญที่ควรเพิ่มก่อนส่งอาจารย์:** จำนวนผู้ทดสอบ วิธีคัดเลือก และตัวชี้วัดที่ชัดเจน

- ทดสอบความถูกต้องของการค้นหาและการกรองข้อมูล
- ตรวจสอบว่าความสัมพันธ์ในกราฟตรงกับข้อมูลต้นทาง
- วัดเวลาหรืออัตราความสำเร็จในการค้นหาบุคคล/ทักษะที่กำหนด
- ประเมินความเข้าใจกราฟและข้อมูลด้วยแบบสอบถามหรือแบบทดสอบงาน (task-based evaluation)
- ประเมินความง่ายต่อการใช้งานด้วยแบบสอบถาม เช่น ระดับความพึงพอใจหรือ SUS หากเหมาะสม
- บันทึกข้อจำกัด เช่น ข้อมูลไม่ครบ ความซ้ำซ้อนของข้อมูล และความซับซ้อนเมื่อจำนวนโหนดเพิ่มขึ้น

## 11. ความเสี่ยงและข้อจำกัดที่คาดไว้

- ข้อมูลจากมหาวิทยาลัยอาจเข้าถึงได้ไม่ครบหรือมีข้อจำกัดด้านสิทธิ์การใช้งาน
- ข้อมูลจากหลายแหล่งอาจมีรูปแบบไม่เหมือนกันและต้องทำความสะอาดก่อนนำมาใช้
- การเชื่อมโยงทักษะกับหลักฐานอาจต้องใช้เกณฑ์หรือการตรวจสอบจากผู้เชี่ยวชาญ
- กราฟอาจอ่านยากเมื่อมีจำนวนโหนดและเส้นเชื่อมจำนวนมาก
- ต้องคำนึงถึงความเป็นส่วนตัว ความถูกต้อง และการอนุญาตให้เผยแพร่ข้อมูลบุคคล
